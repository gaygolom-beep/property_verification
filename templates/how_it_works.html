System Architecture

How the verification pipeline works

From a document upload to a human's final decision, here's every step the platform takes — and which module is responsible for it.

1
Upload & Geocode

An owner adds a property (with address, locality, city, state, PIN) and uploads supporting documents — Title Deed, NOC, Tax Receipt, Sale Agreement. The address is geocoded automatically and pinned on an interactive map.

routes/property_routes.py · routes/geocoding.py
2
OCR — Optical Character Recognition

Every uploaded image or PDF is run through Tesseract OCR (or PDF text extraction) the moment it's uploaded, turning a scanned document into machine-readable text.

routes/ocr.py
3
NLP Field Extraction & Matching

Pattern-based NLP pulls structured fields out of the raw text — owner name, survey number, area, dates, PIN code — then compares them across a property's documents using fuzzy name matching and numeric tolerance, so "Priya Deshmukh" and "Priya D. Deshmukh" aren't flagged as different people.

analysis/extractor.py · analysis/matcher.py
4
Risk Scoring & Anomaly Detection

About nine automated checks run — missing documents, unreadable scans, name/survey/area mismatches, impossible or out-of-order dates, duplicate content, duplicate ownership claims. Each failed check adds explainable points to a transparent 0–100 score, never a black-box number.

analysis/risk.py
5
Human Review Queue

The score can only ever move a property from "Pending" to "In Review" — never straight to Verified or Rejected. An admin opens the Review Queue (riskiest properties first), reads the findings, and makes the actual decision.

routes/analysis_routes.py · templates/analysis/queue.html
Verified & Reported

The final decision is recorded permanently in an append-only audit trail (never overwritten), and a signed-off PDF report can be downloaded — property summary, every finding, and a human sign-off block.

analysis/report.py · routes/verification_routes.py

This pipeline supports technical document-consistency verification only — it is not a legal certification of ownership or title.
